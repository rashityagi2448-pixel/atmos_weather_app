🌦️ Atmos – Weather App
Atmos is my first web development project! It is a simple, interactive and responsive weather application that allows users to search for any city and view its current weather information.

✨ Features
Search weather by city name.
View current temperature and weather conditions.
Get real-time weather information.
Attractive and user-friendly interface.
Responsive design with animations and transitions.

🛠️ Technologies Used
HTML5 – Website structure.
CSS3 – Styling and responsive design.
JavaScript – Functionality and dynamic content.
WeatherAPI – Real-time weather data.
GitHub – Code hosting.
Netlify – Website deployment.

📚 What I Learned
Frontend web development.
API integration and data fetching.
JavaScript and asynchronous operations.
Handling user input and dynamic content.
GitHub and website deployment.
